# 2D Space Simulation backup

Private backup of the Godot 4.6.2 space simulation prototype, captured September 17, 2026.

Download `2d-space-simulation-backup-2026-09-17.zip` and extract it. Import `2d-space-simulation/project.godot` in Godot. The archive includes 483 source, scene, resource, documentation, and test files, plus setup instructions. Generated caches, logs, temporary files, and local saved games are excluded.

The `.sha256` file provides the archive checksum. This repository currently stores a packaged snapshot; source files are inside the ZIP.
